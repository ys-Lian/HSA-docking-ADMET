# HSA-docking-ADMET
2025-2026 MSc Pharmaceutics graduation project @UCL School of Pharmacy - Molecular Docking and Dynamics to Serum Albumin for Improving ADMET Property Prediction of Drugs

The raw data file: open_admet_raw_1.csv, from the OpenADMET community (https://huggingface.co/openadmet).
All .py/.sh files are included in the fold "supercomputer/".
